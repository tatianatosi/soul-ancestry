## Protocolo

1. Localizar a fonte primária ou cópia com proveniência.
2. Registrar hash/ID/caminho, data e responsável quando disponíveis.
3. Ler o conteúdo antes de classificá-lo.
4. Comparar com o estado implementado no GitHub.
5. Classificar como vigente, histórico, substituído, pendente ou conflitante.
6. Nunca atualizar sistema externo somente para fazer o artefato coincidir com a documentação.
