# Shared agent instructions

Read `AGENTS.md` before editing. Its rules are canonical; this file does not duplicate them.

Read the active PR reservations before changing files. Use an isolated branch and declare every changed file and tested/base SHA in the existing PR evidence matrix. The `reservation-sync` automation revalidates all open PRs after reservation changes and main updates. Never merge or publish automatically; human authorization, integration, tests and deployment remain separate.

The owner-authorized contract documentary exception is narrow: only missing documents/annexes, with an audited reason. Do not bypass financial approval, validity, human review, representation of minors or signature requirements.
