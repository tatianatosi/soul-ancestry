# Adendo — Prompts em políticas são execução, não arquivo morto

- Status: vigente (2026-09-11)
- Problema: textos em `docs/politicas/` com prefixo `PROMPT-*` foram tratados como política/arquivo quando a intenção era **executar no Desk**.

## Regra

| Tipo de documento | O que fazer |
|---|---|
| `PROMPT-*`, artefato CA-*-EXECUCAO, Cockpit, Motores unificados | Backlog de **implementação**; status em relatório com evidência de código |
| `politica-*`, MEMORIA, autoridade operacional, fonte-de-verdade | Norma — orientar, não “implementar como tela” |
| Taxonomia / marca / mockup 17+47 | Contrato de nomes e visual — aplicar em fatias na Trilha C |
| Comparativo / histórico Ana / dossiê | Evidência e auditoria — não briefing de feature paralela |

## Prioridade de execução agora (Casos 360 + Pessoa 360)
